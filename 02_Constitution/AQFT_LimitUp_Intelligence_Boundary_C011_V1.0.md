# AQF-T C-011: Limit-Up Intelligence Boundary

Version: V1.0.0 | Status: ✅ FROZEN — Constitution-Level
Date: 2026-07-28 | Source: P2-001 Limit-Up Microstructure Intelligence V1.0

---

## Core Definition

**Limit-Up Intelligence may interpret capital behavior, but shall not directly generate trading decisions.**

---

## MAY

| Rule | Description |
|------|-------------|
| ✅ Classify board types | 一字板/换手板/烂板/回封板/天地板 |
| ✅ Evaluate seal quality | 封单持续性+变化稳定性+撤单比例 |
| ✅ Assess break pressure | 炸板次数+深度+回封耗时 |
| ✅ Provide confidence adjustment | Per board type + time phase |
| ✅ Provide risk modifier | Per board quality |

---

## SHALL NOT

| Rule | Description |
|------|-------------|
| ❌ Generate trading signals | 属于 Decision Intelligence |
| ❌ Override Risk Runtime | 违反 C-001 |
| ❌ Modify Immutable Core | 违反 C-002 |
