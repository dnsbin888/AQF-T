# AQF-T C-015: Confidence Integrity Boundary

Version: V1.0.0 | Status: ✅ FROZEN — Constitution-Level
Date: 2026-07-28 | Source: V3.1-005 Calibration Engine V1.0

---

## Core Definition

**Confidence represents calibrated belief reliability, not expected profit.**

Prediction Accuracy ≠ Trading Profit. Decision Quality ≠ Trading Result.

---

## MAY

| Rule | Description |
|------|-------------|
| ✅ Calibrate confidence | Historical accuracy → adjusted probability |
| ✅ Track sample size | Minimum N≥50 before calibration valid |
| ✅ Apply regime-conditional calibration | Bull/Bear/Recovery different calibration factors |
| ✅ Apply confidence decay | Recent data > historical data |

---

## SHALL NOT

| Rule | Description |
|------|-------------|
| ❌ Profit → Confidence↑ | 赚钱 ≠ 判断正确 |
| ❌ Loss → Confidence↓ | 亏钱 ≠ 判断错误 |
| ❌ Low sample → high confidence | 小样本不得产生高可信度 |
| ❌ Permanent calibration | 校准需要持续更新 |
