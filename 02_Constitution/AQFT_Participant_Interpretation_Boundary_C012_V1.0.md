## Core Definition

**Opponent Model outputs ParticipantHypothesis (行为假设), NOT participant identity (真实身份). AQF-T observes and infers. It does not claim to know.**

---

## MAY

| Rule | Description |
|------|-------------|
| ✅ Classify participant types | Institution/Hot Money/Quant/Retail/Unknown |
| ✅ Infer intent with confidence | Accumulating/Holding/Rotating/Distributing/Panic Selling |
| ✅ Provide evidence chain | Observable signals backing each classification |
| ✅ Provide alternative hypothesis | What else could explain this behavior? |
| ✅ Adjust decision confidence/risk | Per participant intent + confidence |

## SHALL NOT

| Rule | Description |
|------|-------------|
| ❌ Claim participant identity | AQF-T is not 交易所后台, not 公安系统 |
| ❌ Generate trading decisions | 属于 Decision Intelligence |
| ❌ Override Risk Runtime | 违反 C-001 |
| ❌ Modify Immutable Core | 违反 C-002 |

## Key Principle

```
Observed Pattern → Most Consistent With [Participant Type] → Confidence → Hypothesis
NOT: "This is Institution" → "This pattern matches Institution accumulation (conf 0.81)"
```
