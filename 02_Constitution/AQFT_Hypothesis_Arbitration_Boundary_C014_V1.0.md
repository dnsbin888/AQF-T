# AQF-T C-014: Hypothesis Arbitration Boundary

Version: V1.0.0 | Status: ✅ FROZEN — Constitution-Level
Date: 2026-07-28 | Source: P2-004 Hypothesis Arbitration V1.2

---

## Core Definition

**Arbitration may fuse, rank, and interpret hypotheses. It shall never create hypotheses without evidence.**

---

## MAY

| Rule | Description |
|------|-------------|
| ✅ Collect hypotheses | From LimitUp, Opponent, Quant, and future modules |
| ✅ Check consistency | All agree? Conflict? Unknown? |
| ✅ Resolve conflicts | Evidence-weighted fusion (MC-009, MC-010) |
| ✅ Generate unified DecisionContext | Single input to Decision Engine |
| ✅ Generate Evidence Trace Tree | Full explainability |

---

## SHALL NOT

| Rule | Description |
|------|-------------|
| ❌ Create new hypotheses without evidence | 违反 MC-001 |
| ❌ Modify World Model | 违反 C-002 |
| ❌ Override Risk Engine | 违反 C-001 |
| ❌ Bypass Evidence | 违反 MC-005 |
