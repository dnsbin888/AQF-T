---

## Core Definition

**任何原创模块、算法、架构、模型，都没有永久保留权。唯一保留条件：持续创造价值。**

Architecture serves Reality. Reality never serves Architecture.

---

## Rules

| Rule | Description |
|------|-------------|
| No permanent retention | 原创不是护身符。持续价值才是。 |
| Replace if better exists | 外部方案更优 → 替换。不坚持原创。 |
| Remove if value ≈ 0 | 花了三个月、二十篇文档 → 也必须删。 |
| Truth > Ownership | 数据 > 所有权。市场 > 设计者。 |
