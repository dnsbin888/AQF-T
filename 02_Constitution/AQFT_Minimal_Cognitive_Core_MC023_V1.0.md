## Core Definition

**每增加一层认知，都必须证明它产生了不可替代的价值。**

如果删掉它，系统到底损失了什么？回答不了 → 不是核心 → 不要加。

---

## Principle

**认知密度 > 模块数量**

新增任何模块/模型/Agent/Memory/Pipeline 必须通过删减测试：删除后收益/Replay/Decision是否下降？没有→拒绝。
