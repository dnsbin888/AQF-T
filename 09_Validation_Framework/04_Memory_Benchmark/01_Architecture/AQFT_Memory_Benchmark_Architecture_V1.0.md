## 1. Purpose

**Memory Value ≠ Memory Size.** Prove whether AQF-T Memory improves Decision Quality, Risk Control, Pattern Recognition, and Future Adaptation. Not just stores records.

## 2. Four Baselines

| Baseline | Description | Represents |
|----------|-------------|------------|
| B0: No Memory | Market→Decision→Trade | Minimum benchmark |
| B1: Trade Log | Manual review of records | Traditional quant |
| B2: Vector Memory | Embedding→Similarity→Retrieve | Current AI Agent standard |
| B3: AQF-T Memory | Episode→Reflection→Pattern→Failure→Knowledge | Target |

## 3. Four Core Metrics

| Metric | Question |
|--------|----------|
| Decision Improvement Score | Post-Memory vs Pre-Memory decision quality |
| Failure Recurrence Rate | Does Failure Library reduce repeated errors? |
| Knowledge Transfer Score | Can experience from one regime transfer to another? |
| Memory Efficiency (ROI) | Capability_Gain / Memory_Complexity |

## 4. Three Key Experiments

**M001 — Failure Memory Effect**: A(no failure lib) vs B(MEM-003 active). Measure F001-F005 recurrence.

**M002 — Reflection Effect**: Raw Decision vs Decision+Reflection+Knowledge→Future Decision.

**M003 — Memory Compression**: Small high-quality memory vs large low-quality records.

## 5. Constitution

MC-010: If Memory shows no effect → reduce weight. C-009: Memory updates Knowledge, never auto-modifies Decision Rules.
