## 五、V3.6路线（修正版）

| 顺序 | 模块 | 目标 |
|------|------|------|
| P0-1 | 数据生命线 | akshare→EventBus→World Model 真实数据跑通 |

| P0-3 | Model Runtime | LightGBM首次进入AQF-T，做第一次真实预测 |
| P0-4 | 回测引擎 | 自研事件驱动，A股T+1+涨跌停+集合竞价 |
| P1 | 游资情绪引擎 | 涨停梯队/情绪周期/龙虎榜/集合竞价 |

## 六、结论

AQF-T最大瓶颈不是架构，而是缺少市场输入和学习数据。V3.6应停止增加服务数量，全力补齐数据+因子+模型训练三条生命线。
