## 一、核心原则

**不要删除模块。要降低复杂度。KEEP capability, REDUCE complexity, IMPROVE maintainability.**

- 禁止未经 TAF-001 + Retirement Governance 删除核心模块
- 编号冲突是唯一真正架构级问题
- 三层执行体系（Intelligence/Architecture/Runtime）不是重复，是成熟分层
