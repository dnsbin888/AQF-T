## Mode Shift

```
Architecture Era:  Discussion → Design → Freeze → Git
Engineering Era:   Reality → Issue → Experiment → Validation → Knowledge → Upgrade
```

Upgrade comes from real data. Not Architect inspiration.

## EP = Knowledge Production System

Every line of code must answer: Does it help AQF-T learn faster? Validate better? Make fewer mistakes? Be more explainable? If not, don't write it.

## EP by Capability, Not Module

| Cap | Goal |
|-----|------|
| C1 | Read one full day of market data |
| C2 | Generate one complete Belief |
| C3 | Output one Decision Context |
| C4 | Execute one Paper Trade |
| C5 | Record one Episode |
| C6 | Complete one Reflection |

Always runnable. Never "three months of coding, still can't run."

## New Milestone

Not "completed another module." But **"verified another piece of market knowledge."**

## New KPIs (Priority > Returns)

连续运行天数 | Replay成功率 | Decision可解释率 | Calibration ECE | Reflection完整率 | 新知识通过验证率 | Failure Recovery Time | Knowledge Reuse Rate

## Architect Role Shift

From Designer → Architecture Guardian + Science Reviewer + Technology Roadmap Planner. Review technology admission (TAF-001). Review experiment validity. Review knowledge evidence standards. Guard architecture stability.
