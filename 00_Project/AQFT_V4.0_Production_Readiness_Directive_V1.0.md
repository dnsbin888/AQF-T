## 一、V4.0 Identity

**AQF-T = Personal AI Quant Fund System（个人AI量化基金系统）**

不是自动交易机器人。不是指标策略集合。是一个具备市场理解、假设生成、竞争分析、决策判断、风险控制、经验积累、自我验证能力的个人量化认知系统。

## 二、战略升级：从建设系统到运营智能资产

过去：设计模块→增加能力→继续扩展。V4.0：已有能力→真实市场验证→发现不足→局部优化→能力增长。

## 三、规模控制（已冻结）

30-45 modules | 100K-200K LOC | ~150 docs | 10-20 models

个人能力边界内的最大有效复杂度。超过50模块→维护成本指数增长。

## 四、三大原则

**P1 — Intelligence Density > System Size**: 评价标准：一次交易决策包含多少有效认知。不是模块数量。

**P2 — Buy First > Hybrid > Build Unique**: Memory/Agent/Calibration用成熟方案。AQF-T负责知识治理和A股认知。

**P3 — Validate Before Expand**: Problem→Evidence→Benchmark→ROI→Admission. 禁止"感觉缺模块就加模块"。

## 五、资产分层

| Tier | 资产 | 策略 |
|:----:|------|------|
| 1 | World Model, Decision, Experience Evolution, A-Share Combat | **不可替代** ★★★★★ |
| 2 | Memory Infrastructure, Vector Search, Agent Runtime, ML Framework | **成熟技术适配** |
| 3 | 通用算法/数据库/训练框架/基础模型 | **不值得自研→替换** |

## 六、V4.0 阶段

**Alpha**: 数据接入 + Replay + Paper Trading

**Beta**: 模拟资金 + 小仓测试 + Calibration校准

**Production**: 稳定运行 + 风控成熟 + 持续进化

## 七、最大挑战

不是技术。是从设计世界进入真实市场。Architecture Intelligence → Market Intelligence。
