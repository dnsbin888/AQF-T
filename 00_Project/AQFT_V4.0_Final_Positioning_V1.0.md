## 一、最终定位

**AQF-T V4.0 = Personal AI Quant Fund System（个人AI量化基金系统）**

不是 Citadel/Renaissance 级机构平台。不是无限扩展的 AI 研究项目。是个人可维护、对标中小私募、融合世界级AI技术的A股认知交易系统。

## 二、V4.0 目标规模

| 指标 | 目标 |
|------|:--:|
| 核心模块 | 30-45 |
| 代码量 | 100K-200K 行 |
| 设计文档 | ~150 |
| AI 模型 | 10-20 (成熟模型组合) |
| 数据库 | 5-20GB |
| 运行成本 | 个人可承受 |

## 三、核心竞争力

不是"拥有多少模型"。而是"用个人可维护的系统，把世界级AI技术、A股经验、交易纪律、失败学习融合成一个持续进化的交易认知系统"。

**认知密度 > 模块数量**

```
传统量化: Data → Signal → Trade
AQF-T:    Market→Understand→Hypothesize→Compete→Decide→Execute→Reflect→Learn→Evolve
```

## 四、最大风险

不是代码膨胀。是**知识系统膨胀** — 每发现一个想法就增加模块。

**Complexity Budget Principle**: ROI = Capability_Gain / Complexity_Increase. 能力+5% 复杂度+30% → 拒绝。

## 五、技术路线

**Buy First > Hybrid > Build Unique**

基础能力引入成熟方案 (Vector DB, Agent Framework, Calibration, ML Models)。AQF-T原创保留 A股市场知识体系, Decision Boundary, Memory Governance, Combat Intelligence。
