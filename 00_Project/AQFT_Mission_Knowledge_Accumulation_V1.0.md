## Mission

**AQF-T exists to accumulate verified market knowledge, not to accumulate code.**

AQF-T 的使命不是积累代码，而是持续积累经过验证的市场知识。

## Three Layers

| Layer | Change Rate | Content |
|-------|:----------:|---------|
| **OS** | Years | Constitution, Canonical Objects, Interface, Runtime, World Model Framework |
| **Cognition** | Months | Decision, Reasoning, Combat, Failure Memory |
| **Knowledge** | **Daily** | 热点轮动, 高标接力, 情绪周期, 行业轮动, 成交量, 盘口规律 |

## Key Insight

Market changes every day. What changes is not Python, not LangGraph, not FAISS. What changes is market规律. So what should evolve is Knowledge. Not code.

## Knowledge Health Metrics

| Metric | Meaning |

| Active Knowledge Ratio | ACTIVE知识占比 |

| Knowledge Reuse | 被Decision调用次数 |
| False Knowledge Rate | 被淘汰知识比例 |
