## KCR: Knowledge Compound Rate

Not "how many Knowledge units." But "do existing Knowledge units make decisions better?" Decision Accuracy +4%, Calibration +6%, Failure -11% with same Knowledge count = compound. Not accumulation.

## Engineering Era Goal

Architecture Era: Build the right system. Engineering Era: Build the right habits. Long-running systems depend on daily correct engineering behavior, not one great design.
