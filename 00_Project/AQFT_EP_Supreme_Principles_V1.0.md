## Three Supreme Principles

**EP-1: Don't Break the Loop**

Reality→Observation→Belief→Decision→Execution→Outcome→Reflection→Knowledge→Next Decision. Every new code must answer: Does it strengthen this loop, or bypass it? If bypass (e.g. LLM→direct signal→BUY) → REJECT.

**EP-2: Every Knowledge Has a Birth Certificate**

No naked Knowledge. Every entry: ID, Source, Replay, Paper, Evidence, Calibration, Confidence, Applicable Market, Failure Boundary, Version, Retired Reason.

**EP-3: No Invisible Intelligence**

Every Decision must be replayable. Not "BUY". But "BUY. Evidence: K-213, K-402. Belief: 0.83. Confidence: 0.76. Calibration: 0.73. Reason: Trend+Emotion+Liquidity+Opponent." Explainability is not log. It's part of Decision.

## New Slogan

**Run Every Day. Measure Everything. Learn Continuously.**

## New Metric: Learning Velocity

Weekly: Replay→Validated→Accepted→Retired→Knowledge Gain. Measure how fast AQF-T learns. Not how much it knows.
