\# 一、项目简介



AQF-T（Adaptive Quantitative Fusion Trading System）



是一套面向智能量化交易的综合系统。



系统目标：



建立：



数据驱动 + AI融合 + 多策略协同 + 风险控制 + 自动执行 + 持续学习



的完整交易闭环。

\# 三、系统核心理念



\## 1. 风险优先



任何交易决策必须经过风险审核。





\## 2. AI辅助决策



AI负责：



\- 数据分析

\- 模式识别

\- 信号评分

\- 决策解释





\## 3. 全流程可解释



每一次交易必须能够回答：



为什么买？



为什么卖？



为什么控制仓位？





\## 4. 持续学习



每一次交易结果都进入经验系统。
