Version: V1.0.0 | Status: ENGINEERING DRAFT — Phase 1

## 1. Purpose

Routes Experience Intelligence outputs to V2.9 Memory System. Bridge between Experience and Learning.

## 2. Routing Table

| Experience Output | → Memory Layer | Purpose |
|-------------------|---------------|---------|
| TradingEpisode | Episodic Memory | Store complete experience |
| ExperiencePattern | Pattern Memory | Recurring success/failure patterns |
| KnowledgeCandidate | Knowledge Memory | Validated trading principles |
| ExperienceFeedback | Evolution System | Parameter improvement proposals |

## 3. Retrieval

Memory → Experience: "Given current market context, what does past experience suggest?"

Returns: Similar episodes, matching patterns, applicable knowledge.

## 4. Constitution

C-002: Experience writes to Memory (Episode/Pattern/Knowledge). NEVER writes to Immutable Core (S(t)/B(t)/R(t)/RiskState/DecisionRecord).
