# 第一章 模块定位


## 1.1 定义


Human-AI Collaborative Governance 不预测市场，不执行交易，不替代人类。


它负责建立人类智慧与人工智能自主能力之间的治理、协作和控制机制。



## 1.2 核心思想


AI Autonomous + Human Governance = Aligned Intelligence


传统 AI：Human → Command → AI → Execution（AI 不理解意图，人无法理解推理）

AQF-T：Human Intent → AI Understanding → World Reasoning → Decision Proposal → Human-AI Review → Governed Action → Learning

# 第七章 Human Approval Engine


六级自主权限：


| 等级 | 模式 | 说明 |
|------|------|------|
| L0 | Human Only | 纯人工 |
| L1 | AI Suggestion | AI 建议 |
| L2 | Human Approve | 人工确认 |
| L3 | Conditional Auto | 条件自动 |
| L4 | Autonomous with Monitoring | 自动+监控 |
| L5 | Full Autonomous | 完全自主 |


示例：普通调仓 → L4 自动执行 / 重大风险 → L2 人工确认
