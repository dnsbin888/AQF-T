## 二、路径B拆分

```
Path B Alpha → B1/B2/B3:

  B1 Trend (趋势启动):
    场景: 突破平台+放量+趋势加速
    模型: LGBM (日K+100因子)
    标签: 三目标 (爆发概率-风险概率+资金认可度)

  B2 Theme (题材扩散):
    场景: 龙头涨停, 资金寻找补涨
    模型: 情绪因子+板块强度 (规则为主)
    不需要LGBM

  B3 Intraday (盘中强势):
    场景: 上午拉升+7%, 下午冲板
    模型: XGBoost L2 (确认器, 非决策者)
    输入: L2盘口+封单+大单
```

## 三、模型定位修正

```
LGBM (趋势预测 → B1 Trend用):
  旧: 预测未来N日收益率
  新: 三目标标签
    Label 1: 短线爆发 (未来5日最高收益)
    Label 2: 最大回撤 (未来5日最大亏损)
    Label 3: 资金认可 (是否进涨停/连板)
  输出: 机会评分 = 爆发概率 - 风险概率 + 资金认可度

XGBoost L2 (确认器, 非决策者):
  旧: NOW/WAIT 分类
  新: Confirmation Model
    路径A: Perception发现回封 → XGBoost确认盘口质量
    路径B3: Alpha发现强势 → XGBoost确认封板概率
  输出: 盘口质量分 0-1 (不是买/卖)
  融合: Final = Perception×0.7 + XGBoost×0.3
```

## 四、补五个工程模块 (不扩架构, 是补基础设施)

```
EP-01: Market Regime Engine
  输出: 每日市场状态 → 所有策略读取
  文件: strategy/market_regime.py

EP-02: Event Bus
  事件通信: MarketEvent/SignalEvent/RiskEvent/OrderEvent/TradeEvent
  文件: core/event_bus.py

EP-03: Model Registry
  模型版本管理: metadata.json (日期/参数/回测结果)
  文件: learning/model_registry.py

EP-04: Paper Broker
  模拟成交: 滑点/手续费/涨跌停/排队
  文件: execution/paper_broker.py

EP-05: Backtest Engine
  事件驱动回测: A股规则(T+1/涨跌停/费率)
  文件: learning/backtest_engine.py
```

## 五、工程验证阶段 (Phase 0-3)
