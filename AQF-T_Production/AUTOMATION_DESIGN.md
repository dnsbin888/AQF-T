# AQF-T Production — 全自动交易设计

**目标:** 全自动市场结构判断 → 仓位变动 → 全自动交易
**运行:** miniQMT 7×24静默挂机, 无人值守

---

## 一、自动交易主循环

```
每5分钟循环 (盘中 9:30-15:00):

  Step 1: 市场结构判断
    QMT L2数据 → 情绪周期(冰点/回暖/高潮/退潮) + 涨停梯队 + 题材热度
    → 输出: 当前市场状态

  Step 2: 仓位计算
    市场状态 + 当前持仓 + 风控限额
    → 输出: 目标仓位(0-70%)

  Step 3: 策略信号
    市场状态 + L2订单流 + Dragon龙头识别
    → 输出: TradingSignal列表

  Step 4: 风控审批
    每笔信号 → Risk.check() → APPROVE/ADJUST/REJECT

  Step 5: 执行
    APPROVE/ADJUST → QMT下单
    REJECT → 记录日志

  Step 6: 记录
    成交/拒单 → 写入数据库 → Review复盘
```

## 二、全自动市场结构判断

```
输入 (每5分钟):
  QMT L2: 逐笔成交 / 十档盘口 / 大单统计
  akshare: 涨停列表 / 跌停列表 / 连板高度 / 北向资金

计算:
  情绪值 = 涨停×2 - 跌停×3 + 连板×5 + 北向×10
  四阶段: 冰点(<20) / 回暖(20-50) / 高潮(50-80) / 退潮(>80)

自动规则:
  冰点期 → 仓位上限20%, 仅VolumePrice试错
  回暖期 → 仓位上限50%, Dragon+Sentiment
  高潮期 → 仓位上限70%, Dragon重仓
  退潮期 → 仓位上限20%, 禁止买入, 仅平仓
```

## 三、自动仓位变动

```
目标仓位 = 基础仓位 × 情绪系数 × 风险系数

基础仓位: 凯利公式 f* = (p×b-q)/b
情绪系数: 高潮1.0 / 回暖0.8 / 冰点0.4 / 退潮0.2
风险系数: Risk Score<30→1.0 / 31-55→0.7 / 56-75→0.4

自动调仓:
  当前仓位 > 目标仓位 → 自动减仓 (市价卖出)
  当前仓位 < 目标仓位 → 自动加仓 (信号驱动)
  退潮触发 → 强制降至20%

紧急:
  日亏>3% → 停止当日交易
  总回撤>15% → Safe Mode (仅平仓)
  Kill Switch触发 → 清仓+停策略
```

## 四、无人值守要求

```
运行: miniQMT 500MB内存, Windows台式机7×24
监控: 钉钉/微信告警 (异常/成交/日终报告)
恢复: 网络断开→自动重连, QMT崩溃→守护进程重启
日志: 所有决策可追溯 (信号/审批/执行/结果)

每日流程:
  8:00  系统自检 (QMT连接/数据源/风控状态)
  9:15  盘前数据加载 (竞价/情绪预判)
  9:30  自动交易循环启动
  15:00 收盘停止, 拉取龙虎榜
  16:00 自动生成日报告 (钉钉推送)
```

## 五、人工干预接口 (紧急)

```
自动运行中, 保留人工干预:
  - 紧急停止 (Kill Switch)
  - 手动平仓
  - 临时调整仓位上限
  - 暂停特定策略

正常情况: 全自动, 无人值守
异常情况: 钉钉告警 → 人工介入 → 恢复自动
```
