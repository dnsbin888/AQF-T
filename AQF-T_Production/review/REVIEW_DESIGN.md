# 07 Review — 复盘系统

## 复盘闭环

```
交易 → Review(归因) → Experience(经验) → Learning(优化) → 下次更好
```

## 核心功能

```
绩效统计:
  胜率 / 盈亏比 / 夏普比率 / 最大回撤 / 日均收益 / 连续亏损

因子归因:
  每笔交易 → 拆解到因子贡献
  自动发现: 哪些因子有效? 哪些在拖后腿?

幸存者偏差修正:
  IC计算同时包含 已成交 + 买入失败
  不只看赚钱的, 也要看错过的

L2复盘:
  逐笔成交回放 / 主力行为回溯 / 封板质量评估
  复盘→发现→改进

经验库:
  成功案例: 什么环境+什么策略+什么L2信号 → 盈利
  失败案例: 什么环境+什么策略+什么L2信号 → 亏损
  经验标签: 情绪周期/Regime/策略类型/盈亏/原因

复盘节奏:
  日: 当天交易总结 + 信号回顾
  周: 策略绩效 + 因子有效性
  月: 系统优化 + 经验归档
```
