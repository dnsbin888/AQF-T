## 二、炸板分类 (个股级核心) ← 2026实战验证

### 两类炸板

```
洗盘型 (良性 — 等回封):
  位置: 低位/启动期
  走势: 炸板后横盘3-5点, 白线始终在黄线上方
  量能: 缩量, 买盘持续承接
  信号: 主力洗筹, 大概率回封

诱多型 (危险 — 放弃):
  位置: 高位/出货期
  走势: 直线下坠, 无承接
  量能: 放量, 无人接盘
  信号: 主力出货, 次日闷杀
```

### 分类判断条件

```
洗盘型判定 (满足≥3):
  ① 炸板后价格在涨停下方3-5个点横盘
  ② 分时白线 > 黄线 (均价在上)
  ③ 买盘持续消化抛压 (L2大单监控)
  ④ 炸板瞬间有大单接货 (非一路溃散)
  ⑤ 位置: 非高位, 连板≤5

诱多型判定 (任满足2→放弃):
  ① 炸板后直线下坠, 反弹无力
  ② 分时白线 < 黄线, 持续走弱
  ③ 放量但无大单买入
  ④ 位置: 高位, 连板≥7
```

## 三、板块地位量化 ⭐ (Perception 新增)

```
回封板的可靠性取决于板块地位。孤立涨停的回封不可靠。

板块地位评分 (0-1):

  题材涨停家数:
    涨停 ≥ 10家 → 1.0
    涨停 5-9家  → 0.7
    涨停 3-4家  → 0.4
    涨停 < 3家  → 0.0 (不参与)

  龙头-跟风联动:
    龙头拉板 → 跟风3+只跟随 → 1.0
    龙头拉板 → 跟风1-2只   → 0.5
    孤立涨停, 无跟风        → 0.0

  题材阶段:
    新题材启动(首日发酵)    → 1.0
    题材持续(2-3天)        → 0.8
    题材末期(5天+)         → 0.3
    题材退潮               → 0.0

  综合: 板块地位 = max(涨停家数分, 联动分, 阶段分)
         > 0.7 → 主线, 回封可靠
         0.4-0.7 → 次主线, 回封降仓
         < 0.4 → 杂毛, 不参与回封
```

## 四、回封确认 (3条黄金标准 - 量化版) ⭐

```
← 2026实战验证: 满足≥2→进场 (板块地位>0.4前提)

① 缩量回封:
   回封1分钟量 / 一封1分钟量 < 0.7  → 满分
   回封1分钟量 / 一封1分钟量 0.7-1.0 → 半分
   回封1分钟量 / 一封1分钟量 > 1.0  → 0分 (放量=出货嫌疑)

② 快速回封:
   炸板→回封 < 5分钟    → 满分 (资金抢筹强烈)
   炸板→回封 5-10分钟   → 半分
   炸板→回封 10-15分钟  → 低分
   炸板→回封 > 15分钟   → 0分 (资金犹豫, 不参与)
   含义: 资金抢筹意愿强烈

③ 带情绪回封:
   回封时同板块 ≥ 2只联动上涨 → 满分
   回封时同板块 1只联动      → 半分
   回封时无联动              → 0分
   含义: 具备板块号召力, 真龙头

综合评分 = (①+②+③) / 3
  > 0.7  → 入场 (确定性高)
  0.5-0.7 → 降仓入场
  < 0.5  → 不进场

← 检测方法: QMT L2 实时封单变化 + 板块涨速对比
```
