## Dragon 龙头战法

```
龙头判定 (满足≥3):
  连板高度 ≥ 3 (所属题材最高)
  题材涨停 ≥ 5家
  封单额/流通市值 > 5%
  龙虎榜 ≥ 2家游资席位
  竞价封单 > 5000万 + 流通市值 < 50亿
  首板次日高开 ≥ 5% + 放量

买入: 首板打板 / 二板接力(竞价高开3-7%) / 弱转强(前日炸板+次日15min翻红+量比>3)
卖出: 炸板>10min / 竞价低开>3% / 题材涨停<3家 / 连板中断 / 异动(10日涨>80%)
```

## OrderFlow L2订单流

```
大单拆细: 连续同向小单(500-999手)+间隔均匀+价格密集 → 主力吸筹/出货
DDX/DDY/DDZ:
  DDX>0+DDY>0+DDZ放大 → 主力吸筹 ✅
  超大单净流入 BUT 小单也流入 → 诱多 ❌
资金共振: 超大单+大单同时净流入+放量>1.3倍+涨幅1-5% → BUY
```

## LimitUpL2 涨停增强

```
封单系数 = 买一挂单量 / 近5分钟成交均量
  >8: 封单稳固 → 可打板
  3-8: 中等
  <3: 封单虚弱 → 不参与
撤单率 = 近5分钟买一撤单量/买一总挂单量
  >30%: 假封板 → 禁止
队列断层: 前10档有断 → 需求不连续 → 降仓
```
