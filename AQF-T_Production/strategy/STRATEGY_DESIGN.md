# 03 Strategy — 策略引擎


## 策略定位

**游资打板策略, 以回封板为核心进场方式**

```
进场方式优先级 (按确定性和胜率):

  回封板  ★★★★★  二次过滤, 炸板洗筹+回封确认, 胜率70-85%
  二板接力 ★★★★   盈亏比好, 竞价可能进不去, 胜率65%
  首板打板 ★★★    确定性低, 可能封不住, 胜率60%
  排板    ★★     排不进或炸板
  半路    ★      风险最高
```

---

## 一、回封板核心策略 (主力进场方式)

### 漏斗

```
当日涨停池 (QMT实时) → 监控炸板 → 炸板池(3-8只) → 炸板分类 → 回封确认 → 进场

炸板分类:
  洗盘型: 炸板后横盘3-5点 + 白线>黄线 + 买盘承接 → 等回封
  诱多型: 直线下坠 + 无承接 → 放弃
```

### 回封确认 (3条黄金标准, 满足≥2进场)

```
① 缩量回封: 回封成交量 < 一封成交量 (筹码锁定)
② 快速回封: 炸板→回封 < 10-15分钟 (资金抢筹)
③ 带情绪回封: 回封带动同板块联动上涨 (板块号召力)

← 参考: V2.8.6 08_Combat_Intelligence LimitUp OrderFlow
   封单质量/封单轨迹/炸板压力
```

### 进场时机

```
二封确认后立即进场 (确定性最高)
不排板, 不等三封
```

### 风控

```
当日未回封 → 当天放弃
次日低开 > 3% → 无条件离场
单票仓位 ≤ 15%
```

## 二、补充进场方式 (特定条件使用)

### 二板接力 (回暖期/高潮期可用)

```
条件: Dragon识别为龙头 + 竞价高开3-7% + 竞价量能放大
风险: 竞价可能一字板进不去
```

### 首板打板 (仅限特定板型)

```
仅做: 早盘10:30前 + 主流题材先锋 + 分时阶梯式换手
不做: 尾盘板/孤立涨停/非主流题材
```

### 半路 (拉升中买入, 4-8%涨幅)

```
条件: 题材确认 + L2大单持续买入 + 量能放大 + 预判封板概率高
优势: 能买到, 当日即有浮盈
风险: 封板失败回落 → 止损-3%
仓位: ≤ 10%
```

### 排板 (已涨停排队)

```
条件: 换手板 + 封单质量高 + 板上缩量
只排: 回封板二封, 不排一字板首封
优势: 确定性高 (已封板)
风险: 排不进 or 排进就炸
仓位: ≤ 10%
```

## 三、策略选择矩阵

```
情绪周期  →  冰点: 不做, 空仓
             回暖: 回封板 + 二板接力(竞价)
             高潮: 回封板 + 二板接力
             退潮: 不做, 空仓

板型      →  换手板: 回封板 + 二板接力
             一字板: 等换手, 不追
             烂板:   放弃
             回封板: 二封确认后进场
             天地板: 放弃

对手      →  游资接力: 可跟
             量化主导: 回避
             机构建仓: 可参考(慢)
             散户追涨: 回避
```
